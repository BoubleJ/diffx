# GitLab MR 연동 (예정 기능)

아직 구현하지 않은 기능을 정리한 문서다.

## 1. GitLab MR 목록 조회 (구현됨)

- 앱에서 현재 저장소의 GitLab에 열려 있는 MR 목록을 조회한다.
- MR 클릭 시 그 MR의 소스 브랜치와 타겟 브랜치로 diff가 열린다.

## 2. MR에 코멘트 남기기 (구현됨)

- MR을 클릭해 연 상태에서 diff 줄에 코멘트를 남기면 실제 GitLab MR에 해당 줄 코멘트로 등록된다.

## 3. 수동 브랜치 비교의 코멘트는 메모로만 쓴다 (구현됨)

- MR을 거치지 않고 소스/타겟 브랜치를 직접 골라 비교할 때 남긴 코멘트는 GitLab에 전송하지 않는다.
- 지금처럼 앱 안에서만 보이는 메모로 쓴다.

## 4. AI 리뷰 요청 시 추가 지시 입력

- AI 리뷰 패널에 리뷰 방향 프롬프트를 적을 수 있는 입력 영역을 둔다.
- 예: "성능 문제 위주로 봐줘", "타입 안정성만 확인해줘"
- `리뷰 요청` 클릭 시 입력한 내용을 리뷰 프롬프트에 함께 넣어 Claude Code가 그 지시를 반영해 리뷰한다.
- 입력하지 않으면 지금처럼 기본 기준으로 리뷰한다.

## 5. 앱 데이터 저장 여부 묻기

- 앱을 처음 실행할 때 "최근 저장소와 설정을 이 맥에 저장할까요?"를 묻는다.
- `저장`을 고르면 지금처럼 `~/Library/Application Support/reviewHelper`에 최근 저장소 목록, 브랜치 선택, 제외 목록을 기록한다.
- `저장 안 함`을 고르면 이 항목들을 기록하지 않고 앱을 닫으면 사라진다.
- Electron이 자동으로 만드는 캐시 파일은 앱 실행에 필요해서 선택과 상관없이 생긴다.

## 6. diff 영역 코드 하이퍼링크

- diff 코드 안의 import 경로, 함수, 타입 이름을 클릭할 수 있게 한다.
- 클릭 시 해당 파일이나 정의 위치로 이동한다. 변경된 파일이면 diff 카드로, 변경되지 않은 파일이면 파일 내용 보기로 이동한다.

## 7. 프로젝트 전체 디렉토리 구조 트리

- 변경된 파일만 보여주는 지금의 파일 트리와 별도로, 저장소 전체 디렉토리 구조를 보여주는 트리 영역을 둔다.
- 트리에서 파일 클릭 시 파일 내용을 볼 수 있다. 변경된 파일은 트리에서 표시가 구분된다.
