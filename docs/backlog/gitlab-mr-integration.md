# GitLab MR 연동 (예정 기능)

아직 구현하지 않은 기능을 정리한 문서다.

## 1. GitLab MR 목록 조회

- 앱에서 현재 저장소의 GitLab에 열려 있는 MR 목록을 조회한다.
- MR 클릭 시 그 MR의 소스 브랜치와 타겟 브랜치로 diff가 열린다.

## 2. MR에 코멘트 남기기

- MR을 클릭해 연 상태에서 diff 줄에 코멘트를 남기면 실제 GitLab MR에 해당 줄 코멘트로 등록된다.

## 3. 수동 브랜치 비교의 코멘트는 메모로만 쓴다

- MR을 거치지 않고 소스/타겟 브랜치를 직접 골라 비교할 때 남긴 코멘트는 GitLab에 전송하지 않는다.
- 지금처럼 앱 안에서만 보이는 메모로 쓴다.

## 구현 전에 정할 것

- GitLab 인증 방식: 개인 액세스 토큰을 직접 입력받을지, `glab` CLI 로그인 정보를 쓸지
- GitLab 주소와 프로젝트 판별: `origin` 원격 URL에서 GitLab 호스트와 프로젝트 경로를 읽을지
- MR 목록 범위: 열린 MR 전체를 보여줄지, 내가 작성했거나 리뷰어로 지정된 MR만 보여줄지
- 코멘트 등록 시점: 코멘트를 달 때마다 바로 올릴지, 모아 두었다가 한 번에 올릴지
